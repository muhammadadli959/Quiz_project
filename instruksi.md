Buat aplikasi kuis pilihan ganda di mana pengguna dapat memasukkan nama, menjawab serangkaian pertanyaan dan melihat skor akhir dari nama pengguna tersebut. 

Hal-hal berikut bersifat wajib 
1. Aplikasi harus menggunakan StatelessWidget dan StatefulWidget sesuai kebutuhan. 
2. Aplikasi memiliki minimal 2 (dua) halaman dan menerapkan navigasi antar-halaman. 
3. Komponen UI yang digunakan berulang harus dibuat sebagai widget terpisah dalam file berbeda (reusable widget). 
4. Gunakan aset seperti gambar atau ikon untuk memperindah tampilan aplikasi. 
5. Gunakan font kustom (bukan font bawaan Flutter) agar tampilan lebih menarik dan konsisten dengan desain. 
6. Pastikan ukuran elemen UI bersifat dinamis, menyesuaikan ukuran layar perangkat mobile (tidak menggunakan nilai yang di-hardcode). 
7. Terapkan state management sehingga progres jawaban pengguna tidak hilang ketika layar perangkat dirotasi atau berpindah antarhalaman. 
8. Tidak perlu menggunakan database (data cukup bersifat lokal atau dummy). 
9. Gunakan GitHub sebagai alat pelacak kemajuan proyek. Lakukan commit setiap kali menyelesaikan fitur tertentu, bukan hanya mengunggah proyek di akhir. 
10. Desain aplikasi bersifat bebas. Semakin detail, menarik, dan lengkap fitur yang dibuat, maka peluang memperoleh nilai lebih tinggi semakin besar. 


Bonus, (Optional) 
1. Menerapkan dual-theme (Dark and Light Mode). 
2. Mengimplementasikan konsep adaptive & responsive design sehingga tampilan aplikasi tetap rapi dan proporsional saat dijalankan di perangkat tablet atau browser (web view).

Peringatan:  Hal-hal berikut mempengaruhi penilaian sebagian atau sepenuhnya. 
1. Struktur proyek tidak efisien, misalnya setiap pertanyaan dibuat pada file terpisah (contoh: screen1.dart, screen2.dart, dan seterusnya). 
2. Proyek tidak dapat dijalankan atau terdapat error yang dapat mengambat penggunaan aplikasi  
3. Terdapat tampilan yang tidak rapi atau mengalami overflow. 
5. Tidak menggunakan github sebagai alat untuk melacak perkembangan kode atau hanya mengupload proyek di akhir ke github. 
6. Telat mengumpulkan.
